**Sistema de Gestión Comercial para Artesanías de Olla de Barro y Canastas Tejidas a Mano**

## Descripción

Este apartado contiene el informe realizado sobre los **estándares de calidad relacionados con Stellar y Drips**, considerando su posible aplicación al proyecto **Open Hub Tec – Mixteca**.

El análisis se enfoca en aspectos como:

* Calidad del software.
* Seguridad.
* Código abierto.
* Transparencia.
* Trazabilidad.
* Mantenibilidad.
* Financiamiento de proyectos de código abierto.
* Adaptación a condiciones de conectividad limitada.

## Objetivo

Analizar las características de Stellar y Drips para identificar prácticas y conceptos que puedan relacionarse con la calidad, seguridad, transparencia y sostenibilidad del proyecto Open Hub Tec – Mixteca.

## Stellar

Se analiza Stellar como una tecnología blockchain de código abierto y su posible relación con:

* Pagos.

* Contratos inteligentes.
* Seguridad.
* Trazabilidad.
* Desarrollo de aplicaciones.

## Drips

Se analiza Drips como una plataforma relacionada con el financiamiento de proyectos y dependencias de código abierto.

Se consideran aspectos como:

* Financiamiento.
* Sostenibilidad.
* Transparencia.
* Dependencias de software.
* Mantenimiento de proyectos de código abierto.
